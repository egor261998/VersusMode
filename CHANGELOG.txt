Versus Mode changelog
=====================

3.0.11 — Complete known native enemy portrait mappings (2026-09-27)
-----------------------------------------------------------------

- Added the native Ogryn Houndmaster portrait to the shared HUD/picker mapping.
- Other confirmed native portraits were already mapped; selectable roster unchanged.

3.0.10 — Right-side Heretic player HUD (2026-09-27)
--------------------------------------------------

- Added enemy portraits, player names, current breeds and health on the right.
- Dead players show their next breed and live respawn countdown.
- Host sends a separate HUD snapshot every 0.5 seconds, accepted only from host.
- Bots and Psykhanium practice are excluded; stale client snapshots expire.

3.0.9 — Psykhanium Heretic practice (2026-09-27)
------------------------------------------------

- In the local shooting range, roster/selection keys open the enemy cards directly.
- Selecting a card spawns and controls that enemy without match roles or cooldowns.
- Return to Operative restores possession state and removes the training spawn.
- Training is restricted to the authoritative local shooting range.
- Mocked logic checked; actual Psykhanium gameplay still needs verification.

3.0.8 — Per-player Heretic respawn cooldowns (2026-09-27)
----------------------------------------------------------

- Death locks that breed for the controlling player for 60 seconds.
- Picker cards show live cooldowns and disable unavailable choices.
- Host validates selection and spawning; remaining times replicate to clients.
- Automatic reinforcement picks an available breed, or waits for the earliest cooldown.

3.0.7 — Standalone Heretic night vision (2026-09-27)
--------------------------------------------------

- Embedded the adapted Preysight optics and fade code, with author attribution.
- Added native green overlay, vignette, procedural scanlines and grain.
- Removed the separate Preysight/SimpleAssets dependencies and cross-mod hooks.
- Reset vision on role changes, disable, unload and game-state exits.
- Standalone optics and Lua checks passed; in-game visuals remain unverified.

3.0.6 — Preysight integration (2026-09-27)
-----------------------------------------

- Use the separate unmodified Preysight mod for optics, colour overlay and audio.
- Gate activation by Heretic role; adapt its local illuminator to our free-flight camera.
- Replace the old brightness slider with Preysight's own effect settings.
- Requires Preysight; SimpleAssets supplies optional grain and scanlines.
- Integration logic checks passed; in-game rendering remains unverified.

3.0.5 — Client lobby role synchronization (2026-09-27)
----------------------------------------------------

- Refresh client role labels immediately when a lobby plan arrives.
- Request fresh plans every two seconds while the preparation view is open.
- Prefer the active connection role over stale preparation state.
- Isolated label transitions passed; multiplayer validation remains pending.

3.0.4 — Free aim on possession (2026-09-27)
------------------------------------------

- Start host/client possession with target lock disabled.
- Free-aim-capable casual enemies start in Advanced mode to prevent auto-lock.
- Keep Q targeting controls available for explicit manual switching.

3.0.3 — Poxburster knockback and shot cooldowns (2026-09-27)
----------------------------------------------------------

- Restored native stagger/knockback for controlled Poxbursters only.
- Grenadiers retain stagger immunity; suppression handling is unchanged.
- Sniper and Trapper shots remain immediate, with a two-second cooldown.
- Regular and long-range Trappers share the cooldown and HUD indication.
- Isolated cooldown boundary and immunity checks passed; live play not tested.

3.0.2 — Local night vision lighting (2026-09-27)
-----------------------------------------------

- Replaced the exposure boost with a camera-following local white fill light.
- Added package loading and cleanup for role changes, world transitions and unload.
- Fill light has no shadows or volumetric beam, with an 80 m outer radius.
- Lifecycle checks passed; visual balance requires in-game validation.

3.0.1 — Captain phase crash repair (2026-09-27)
----------------------------------------------

- Repair invalid Captain phase requests against the current combat range and
  the live loadout before the native phase transition runs. Prefer a valid
  current phase, then a valid entry phase; preserve normal transitions.
- Reproduced the plasma_pistol/melee crash from the server log in an isolated
  native-function test and verified the repaired phase and weapon state.
- Host and participating clients must all use version 3.0.1.
- In-game server validation remains pending.

3.0.0 — Local custom build (2026-09-26)
--------------------------------------

- Added one-click reinforcement cards with authoritative selection and HUD confirmation.
- Restricted the reinforcement roster and select the nearest target on Q.
- Fixed Q hold, gunner aiming/fire timing, and native gunfire FX configuration.
- Suppressed involuntary staggering and suppression while controlling a living enemy.
- Added automatic, adjustable Heretic night vision through an exposure boost.
- Added a wider fallback spawn search when normal safe spawning fails, relaxing
  visibility and distance limits while retaining navmesh and headroom checks.
- Host and participating clients must all use version 3.0.0.
- Lua syntax and isolated logic checks passed; the newest vision and spawn changes
  still require in-game visual and multiplayer validation.

0.1.2 — Stable
--------------

- Added Scab Gunner, Dreg Gunner, and Reaper to the possession allowlist and
  Versus Mode reinforcement selection.
- Mapped native gunfire and melee actions, including Dreg bayonet and Reaper
  push, with camera-directed shooting and command selection while in cover.
- Added HUD action labels in English, Simplified Chinese, and Traditional
  Chinese.
- Controlled Elites now use the Specialist third-person distance, horizontal
  offset, height adjustment, and starting pitch.
- Gunner auto lock now loses survivors inside smoke beyond 4 metres unless the
  Gunner is in the same smoke cloud. Free aim remains available.
- Possessed Gunners can strafe during ranged volleys using native directional
  speeds scaled by the Movement speed setting. Aim and rotation handling follow
  the native strafe-shoot path, including the Reaper's left strafe.
- Casual firearm commands now complete only when the native final shot fires.
- Requires the host and participating Realms clients to use the same 0.1.2
  build. Lua 5.1 validation passed (9 compiled files; 1,387 isolated
  assertions). The user tested the final build in game and reports it looks
  good. Realms client validation remains pending.

0.1.0 — Public Testing
----------------------

- Established the permanent VersusMode internal identity and package layout.
- Added host-controlled Operative and Heretic team assignment for SoloPlay and
  compatible Realms sessions.
- Added supported Specialist, Elite, Boss, and variant possession.
- Added Adaptive Combat, Direct Combat, target lock, free aim, reinforcement,
  deployment, camera, spectating, health-rule, and experimental traversal tools.
- Added English, Simplified Chinese, and Traditional Chinese UI text.
- Added persistent white Operative outlines, red locked-target outline/brackets,
  and green allied-Heretic outlines.
- Stabilized Realms-client animation delivery with transition-only locomotion
  synchronization and an exact-event fallback for missed native animation RPCs.
- Restored Pox Hound steering after pounce completion, cancellation, and failure.
- Guarded possession HUD cleanup against destroyed RemotePlayer entries.
- Kept remote Heretic breed assignment private from Versus Mode's host notices.
- Added a local Show attack log option, disabled by default, while preserving
  reinforcement, assignment, death, and error notices.
- Initialized Deployment View immediately from the active streaming anchor when
  a Heretic team assignment is applied as gameplay begins.
- Recreated an early lobby-assignment Deployment View at possession time so the
  rendered camera cannot remain attached to the hidden Operative shell.
- Prevented an invalid replicated camera node from crashing an Operative client
  during death, observer, or mission-outro camera transitions.
- Protected automatic Boss takeover from a carried-over Possess-key release
  that could relinquish the newly assigned Boss in the same update.
- Recreated Versus Mode's native Deployment View manager between missions so
  Specialist respawns cannot reuse a destroyed previous-level viewport.
- Started a fresh editable Heretic roster plan on every Realms preparation
  lobby entry, including consecutive missions in the same session.
- Allowed a Daemonhost's native warp-grab execution sequence to finish a
  downed Operative when initiated through Adaptive Strike.

This public release contains the fixes validated through the temporary
Versus Mode (Test) 0.1.12 series. It is not network-compatible with that series.
