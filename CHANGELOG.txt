Versus Mode changelog
=====================

3.0.28 - Reload without movement lock (2026-09-27)
------------------------------------------------

- R interrupts gunner fire and blocks only primary shooting for two seconds.
- Keep local/remote movement and normal locomotion animations enabled.
- Remove forced reload/recovery animation; retain melee during the firing lock.

3.0.27 - Fix melee circle projection (2026-09-27)
-----------------------------------------------

- Convert camera screen X/Y into the X/Z plane expected by Gui.triangle.
- Correct both circle outline and fill; discard camera depth for GUI vertices.
- Add a render regression check for all 144 triangles and offscreen hiding.

3.0.26 - Complete enemy icon coverage (2026-09-27)
------------------------------------------------

- Retain seven native game portrait materials where available.
- Draw original pixel portraits for missing breeds in all three portrait surfaces.
- Cache merged pixel rectangles; fall back on missing material/render errors.
- Add an option to force drawn icons if native materials silently render white.
- Include a 31-icon gallery and coverage/render fallback checks.

3.0.25 - Playable Shotgunners (2026-09-27)
----------------------------------------

- Add Scab and Dreg Shotgunners with native shooting and melee commands.
- Hold the correct combat range and aim at the crosshair without removing pellet spread.
- Reuse controlled weapon animation aiming and restore it on release.
- Expand selection to 28 cards and add both melee guide checkboxes.

3.0.24 - Host Trapper/Sniper shot cooldown (2026-09-27)
----------------------------------------------------

- Add a shared host slider from 3 to 30 seconds, default 3 seconds.
- Apply it to controlled Snipers and Trappers, including Sniper Netter.
- Recalculate active cooldowns from the last shot and refresh client status.
- Preserve server authority; client preferences cannot change shot timing.

3.0.23 - Expanded Heretic roster (2026-09-27)
-------------------------------------------

- Add Armored Hound, Mauler, Mutant and all ten boss breeds to selection.
- Expand the picker to 24 cards, including the optional Sniper Netter.
- Add Mauler strike, cleave and moving strike with its melee guide checkbox.
- Initialize only newly spawned Daemonhost reinforcements awake; roll back unavailable replication.

3.0.22 - Match gunner animation to free-aim shots (2026-09-27)
-----------------------------------------------------------

- Feed the camera shot point into native controlled animation aiming.
- Turn the body toward that point and keep AI animation rotation disabled in free aim.
- Restore native target animation on lock; retain native aim replication and cleanup.

3.0.21 - Red melee area guide (2026-09-27)
-----------------------------------------

- Show a red outline and translucent disc around the melee impact guide.
- Project the guide onto static ground, using native radius/half-width when available.
- Retain per-enemy visibility settings and committed aim direction.
- The circle is a visual approximation, not a native hitbox guarantee.

3.0.20 - Portrait ammo counter and reload interruption (2026-09-27)
-----------------------------------------------------------------

- Move the native burst counter below the controlled enemy health bar.
- R stops ranged fire and enters a two-second weapon recovery instead of firing.
- Use only supported animation events, with native gun-jam/out-of-aim fallback.
- Replicate recovery to clients and prevent attacks/locomotion replacing it.
- Preserve native burst counts; no custom magazine or reserve ammunition.

3.0.19 - Russian localization and percent-format fixes (2026-09-27)
----------------------------------------------------------------

- Escape literal percent signs in night-vision strength and tint labels.
- Add 577 missing Russian translations for settings, HUD, actions and messages.
- Keep all format arguments compatible with the existing English strings.
- Validate all 634 keys, 2426 localized formats and literal/settings references.

3.0.18 - Freeze grenade HUD on the committed throw (2026-09-27)
------------------------------------------------------------

- Preserve solved trajectory points, bounces and impact area with the grenade launch.
- Render the committed arc during wind-up instead of recalculating the camera arc.
- Replicate bounded, validated arc points from the host to the controlling client.
- Hold the client preview pending confirmation and expire unanswered requests.
- Test both bombers, interrupted throws, pending requests and arc serialization.

3.0.17 - Lock the Hound's charged pounce (2026-09-27)
--------------------------------------------------

- Primary input during the held aimed-pounce preview freezes its charge.
- Keep direction adjustable and launch on Secondary release; reset for each preview.
- Show locked charge in the HUD and consume Primary so it cannot launch another attack.
- Recalculate the final preview on release and retain the existing host validation.
- Add regression checks for all three Hound breeds and custom-input release handling.

3.0.16 - Native burst HUD and night-vision scale (2026-09-27)
----------------------------------------------------------

- Show native burst shots remaining/total for controlled Scab/Dreg Gunners and Reapers.
- Standard Reload input restarts their ranged burst, including on clients.
- Keep native burst sizes and cadence; do not introduce magazines or reserve ammo.
- Correct night-vision strength: 0 is off, 50 is half, 100 is full configured effect.
- Add burst accounting and restart regression checks.

3.0.15 - Per-enemy melee aiming guide (2026-09-27)
------------------------------------------------

- Add a world-projected aiming point using melee command direction and reach.
- Show ray contacts, locked targets in reach and centres for local area attacks.
- Add 20 independent checkboxes in a dedicated settings group, enabled by default.
- Hide the guide during ranged attacks and menus; replicate committed aim angles
  for client-side melee previews without changing combat targeting.
- Update the DMF card version and add focused preview regression checks.

3.0.14 - Key-operated, adjustable night vision (2026-09-27)
---------------------------------------------------------

- Add a dedicated local night-vision settings group and rebindable N toggle.
- Night vision starts OFF and can only be enabled by its key on the Heretic side.
- Add strength (default 50%), fill intensity, distance, exposure and tint sliders.
- Default to broad fill light with zero added exposure and natural colors.
- Remove activation flash, blur, scanlines, grain and vignette.
- Test key gating, settings defaults, neutral optics and role-exit cleanup.

3.0.13 - Optional Gunner target lock (2026-09-27)
----------------------------------------------

- Scab/Dreg Gunners and Reapers start in free aim; holding Q toggles target lock.
- In lock mode, Q selects the nearest valid target and native aiming tracks it.
- Camera aim and the Scab/Dreg spread override apply only with lock disabled.
- Add regression checks for mode toggles, client requests and aim routing.

3.0.12 - Crosshair accuracy and review fixes (2026-09-27)
-------------------------------------------------------

- Controlled Scab and Dreg Gunners resolve each shot from the current camera aim;
  AI spread and dodge targeting no longer redirect their hit scan.
- Preserve per-player breed cooldowns across role changes/rejoins within a match.
- Account for snapshot age and use consistent cooldown readiness in the HUD.
- Explicit Versus spawns retain the selected breed despite replacement mutators.
- Check training spawn obstruction and restore previous possession on switch failure.
- Fade night optics when returning from the Heretic camera.
- Cache host team snapshots and refresh the team HUD at most ten times per second.
- Add portable Lua parsing and mocked regression checks under tests/.

3.0.11 — Complete known native enemy portrait mappings (2026-09-27)
-----------------------------------------------------------------

- Added the native Ogryn Houndmaster portrait to the shared HUD/picker mapping.
- Other confirmed native portraits were already mapped; selectable roster unchanged.

3.0.10 — Right-side Heretic player HUD (2026-09-27)

- Added enemy portraits, player names, current breeds and health on the right.
- Dead players show their next breed and live respawn countdown.

0.1.2 — Stable
--------------

- Added Scab Gunner, Dreg Gunner, and Reaper to the possession allowlist and
  Versus Mode reinforcement selection.
- Mapped native gunfire and melee actions, including Dreg bayonet and Reaper
  push, with camera-directed shooting and command selection while in cover.
- Added HUD action labels in English, Simplified Chinese, and Traditional
  Chinese.
- Controlled Elites now use the Specialist third-person distance, horizontal
  offset, height adjustment, and starting pitch.
- Gunner auto lock now loses survivors inside smoke beyond 4 metres unless the
  Gunner is in the same smoke cloud. Free aim remains available.
- Possessed Gunners can strafe during ranged volleys using native directional
  speeds scaled by the Movement speed setting. Aim and rotation handling follow
  the native strafe-shoot path, including the Reaper's left strafe.
- Casual firearm commands now complete only when the native final shot fires.
- Requires the host and participating Realms clients to use the same 0.1.2
  build. Lua 5.1 validation passed (9 compiled files; 1,387 isolated
  assertions). The user tested the final build in game and reports it looks
  good. Realms client validation remains pending.

0.1.0 — Public Testing
----------------------

- Established the permanent VersusMode internal identity and package layout.
- Added host-controlled Operative and Heretic team assignment for SoloPlay and
  compatible Realms sessions.
- Added supported Specialist, Elite, Boss, and variant possession.
- Added Adaptive Combat, Direct Combat, target lock, free aim, reinforcement,
  deployment, camera, spectating, health-rule, and experimental traversal tools.
- Added English, Simplified Chinese, and Traditional Chinese UI text.
- Added persistent white Operative outlines, red locked-target outline/brackets,
  and green allied-Heretic outlines.
- Stabilized Realms-client animation delivery with transition-only locomotion
  synchronization and an exact-event fallback for missed native animation RPCs.
- Restored Pox Hound steering after pounce completion, cancellation, and failure.
- Guarded possession HUD cleanup against destroyed RemotePlayer entries.
- Kept remote Heretic breed assignment private from Versus Mode's host notices.
- Added a local Show attack log option, disabled by default, while preserving
  reinforcement, assignment, death, and error notices.
- Initialized Deployment View immediately from the active streaming anchor when
  a Heretic team assignment is applied as gameplay begins.
- Recreated an early lobby-assignment Deployment View at possession time so the
  rendered camera cannot remain attached to the hidden Operative shell.
- Prevented an invalid replicated camera node from crashing an Operative client
  during death, observer, or mission-outro camera transitions.
- Protected automatic Boss takeover from a carried-over Possess-key release
  that could relinquish the newly assigned Boss in the same update.
- Recreated Versus Mode's native Deployment View manager between missions so
  Specialist respawns cannot reuse a destroyed previous-level viewport.
- Started a fresh editable Heretic roster plan on every Realms preparation
  lobby entry, including consecutive missions in the same session.
- Allowed a Daemonhost's native warp-grab execution sequence to finish a
  downed Operative when initiated through Adaptive Strike.

This public release contains the fixes validated through the temporary
Versus Mode (Test) 0.1.12 series. It is not network-compatible with that series.
